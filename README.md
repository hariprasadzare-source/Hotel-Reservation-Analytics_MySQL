# Hotel Reservation Analytics Using MySQL

## Project Overview

This project analyzes hotel reservation data using **MySQL** to generate useful business insights from hotel bookings, guests, stays, staff, and rooms.

The project includes a relational database with **6 connected tables**: Hotels, Guests, Staff, Rooms, Bookings, and Stays. SQL queries were used to explore the data and answer important business questions related to revenue, booking behavior, stay performance, staff workload, room usage, cancellations, and no-shows.

## Objectives

* Analyze hotel booking and revenue performance
* Identify the most popular hotels and booking channels
* Understand guest booking behavior
* Compare Individual and Corporate guests
* Analyze stay status, cancellations, and no-shows
* Evaluate staff workload and ratings
* Identify the most frequently used room types
* Find booking and stay-related problem areas
* Generate business recommendations from the analysis

## Key Insights

* **StayPoint Mumbai Grand** had the highest number of bookings with 224 bookings.
* **Website** generated the highest revenue at approximately 15.3 million.
* Booking volume increased from 885 in 2024 to 1,048 in 2025.
* 322 out of 339 guests with bookings were repeat guests.
* Checked-out stays accounted for 66.16%, while no-shows accounted for 16.94% and cancellations for 15%.
* **Standard rooms** were the most frequently used room type with 1,440 stays.
* **Mobile App** had the highest number of cancellations.
* **StayPoint Mumbai Residency** had the highest number of problem stays.
